# 🍽️ La Mechita

Sitio web de un restaurante de comida típica guatemalteca desarrollado como proyecto de práctica.

---

## 🌐 Demo
👉 https://joshyjx.github.io/mechita/

---

## 📌 Descripción

"La Mechita" es un sitio web diseñado para representar un restaurante tradicional, mostrando su identidad, menú, galería y sistema de reserva.

El objetivo fue aplicar conocimientos de desarrollo web utilizando HTML, CSS y Bootstrap.

---

## ⚙️ Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5

---

## 📱 Características

✅ Diseño responsive (adaptable a móviles)
✅ Navegación entre múltiples páginas
✅ Menú dinámico con tarjetas
✅ Galería de imágenes
✅ Sección de contacto
✅ Formulario de reservas (simulado)

---

## 🚀 Funcionalidades

- Navegación fluida entre secciones
- Diseño moderno con Bootstrap
- Uso de estilos personalizados
- Simulación de formulario de reservas
